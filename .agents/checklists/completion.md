# Completion Checklist

## Implementation

- [ ] Requested functionality implemented
- [ ] Scope remained focused
- [ ] Existing behavior preserved where required

## Verification

Mark each item as:

- PASS
- FAIL
- UNVERIFIED

Checks:

- [ ] Build
- [ ] Type checking
- [ ] Lint
- [ ] Automated tests
- [ ] Runtime behavior
- [ ] Responsive behavior
- [ ] Database behavior
- [ ] Authorization behavior

## Final status

Choose one:

- VERIFIED
- PARTIALLY VERIFIED
- UNVERIFIED
- FAILED

Never mark an untested behavior as VERIFIED.
