# Bug Fixing Skill

Use for defects, regressions, errors, and broken behavior.

## Process

1. Reproduce the problem.
2. Identify the affected behavior.
3. Trace the relevant code/data flow.
4. Determine the root cause.
5. Implement the smallest safe fix.
6. Check for regression risk.
7. Verify the original failure is resolved.
8. Report the root cause, fix, and verification.

Do not hide symptoms with arbitrary workarounds when the root cause can be addressed safely.
