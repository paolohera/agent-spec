# Code Review Skill

Review code critically against the requirement.

Check:

- correctness
- acceptance criteria
- architecture
- duplication
- maintainability
- error handling
- security
- authentication
- authorization
- database integrity
- responsive UI
- accessibility
- performance where relevant
- regression risk
- unnecessary dependencies
- unnecessary changes

A passing build is not sufficient evidence of correctness.

If behavior cannot be verified, mark it UNVERIFIED.
