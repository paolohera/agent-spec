# Feature Development Skill

Use for new functionality or meaningful changes to existing functionality.

## Process

### 1. Understand

Identify:

- user goal
- expected behavior
- acceptance criteria
- explicit constraints

### 2. Investigate

Inspect the existing implementation before deciding what to create.

### 3. Plan

Identify:

- files to modify
- files to create
- dependencies
- database impact
- authorization impact
- UI states
- verification strategy

### 4. Implement

Build the smallest complete solution.

### 5. Verify

Run relevant checks and test the actual behavior when possible.

### 6. Acceptance review

Check every acceptance criterion.

### 7. Report

State:

- implemented
- verified
- unverified
- remaining issues
- risks
