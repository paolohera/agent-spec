# UI Development Skill

Use for visual, responsive, interaction, and component changes.

## Process

1. Inspect the current page/component.
2. Identify existing design patterns.
3. Identify reusable components.
4. Understand desktop and mobile requirements.
5. Plan affected states.
6. Implement.
7. Verify:
   - desktop
   - mobile
   - loading
   - empty
   - error
   - success
   - hover/focus/active states
   - keyboard accessibility where relevant
8. Review against the requested design.

Do not treat a screenshot matching one viewport as proof of responsive correctness.
