# Feature Workflow

```text
Requirement
    ↓
Acceptance criteria
    ↓
Investigation
    ↓
Relevant context + skill
    ↓
Plan
    ↓
Implementation
    ↓
Verification
    ↓
Acceptance review
    ↓
Fix discovered issues
    ↓
Re-verify
    ↓
Final report
```

## Completion rule

Do not declare VERIFIED unless meaningful verification was actually performed.
